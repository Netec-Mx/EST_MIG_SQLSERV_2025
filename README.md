# Migración Microsoft SQL Server 2025

## Plataforma de laboratorios

Te damos la bienvenida a la plataforma de laboratorios del curso Migración Microsoft SQL Server 2025. Aquí aplicarás la revisión de entornos, el análisis de rendimiento, el uso de IA como apoyo técnico, la configuración del servidor, la seguridad y la migración de bases de datos mediante prácticas guiadas.

## Lista de laboratorios

Haz clic en el título de cada práctica para abrir su guía. Los nombres de los capítulos, las prácticas y sus duraciones corresponden al temario del curso; las descripciones reflejan las actividades documentadas en el repositorio.

## Capítulo 1: Contexto y arquitectura moderna SQL en Windows Server\*

### [Práctica 1. Revisión del entorno: Windows Server 2022, SQL Server 2025 y SSMS actualizado](Capitulo01/README.md)

- Descripción: Verifica Windows Server 2022, SQL Server 2025, SSMS, servicios, conectividad y parámetros de instancia. Crea la base Sql2025Lab con compatibilidad 170, recuperación FULL y Query Store, carga datos de ejemplo y documenta la línea base del entorno.
- ⏱️ Duración estimada: 45 min.

## Capítulo 2: Novedades de SQL Server 2025

### [Práctica 2. Comparación: Comparar ejecución de queries, Antes vs optimizadas automáticamente y Uso de herramientas de diagnóstico en SSMS](Capitulo02/README.md)

- Descripción: Registra métricas y planes de ejecución para identificar consultas costosas y regresiones. Aplica índices, actualización de estadísticas, reescritura de consultas y correcciones controladas con Query Store; compara CPU, duración y lecturas antes y después.
- ⏱️ Duración estimada: 70 min.

## Capítulo 3: IA aplicada a SQL Server (Copilot)

### [Práctica 3. IA Generar queries con Copilot, Explicar un query complejo, Optimizar consultas usando IA y Documentación automática de objetos](Capitulo03/README.md)

- Descripción: Utiliza GitHub Copilot Chat para generar y explicar consultas T-SQL, proponer optimizaciones y preparar documentación de objetos. Contrasta cada sugerencia con planes de ejecución y métricas, y documenta las decisiones de aceptación, modificación o rechazo.
- ⏱️ Duración estimada: 95 min.

## Capítulo 4: Integración con Windows Server 2025

### [Práctica 4. Optimización: Validación de configuración óptima del servidor y Ajustes básicos de performance](Capitulo04/README.md)

- Descripción: Revisa memoria, CPU, paralelismo, almacenamiento, TempDB y configuración del servidor. Aplica ajustes básicos reversibles, compara resultados y verifica Resource Governor sobre el entorno Windows Server 2022; Windows Server 2025 se aborda como contexto tecnológico.
- ⏱️ Duración estimada: 70 min.

## Capítulo 5: Seguridad y cumplimiento

### [Práctica 5. Configuración: Roles, Auditoría y Encriptación](Capitulo05/README.md)

- Descripción: Configura logins, usuarios y roles de mínimo privilegio, enmascaramiento dinámico y auditoría de eventos. Habilita cifrado TDE, respalda el certificado y valida los permisos, los registros de auditoría y la protección de los respaldos.
- ⏱️ Duración estimada: 80 min.

## Capítulo 6: Estrategias de migración (2019/2022 → 2025)

### [Práctica 6. Simulación de migración: Simulación de migración y Validación post-migración](Capitulo06/README.md)

- Descripción: Simula la migración de una base desde SQL Server 2017 hacia SQL Server 2025, conforme a la guía disponible. Inventaría el origen, evalúa compatibilidad, realiza respaldo y restauración, y valida datos, objetos, seguridad e integridad. Completa una cadena de respaldos y un trabajo de SQL Server Agent en el destino.
- ⏱️ Duración estimada: 90 min.
